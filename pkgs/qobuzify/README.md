# Qobuzify

Qobuz desktop client with synchronized lyrics, packaged from the upstream AppImage on x86_64 Linux and app bundle on Apple Silicon macOS. Install `packages.x86_64-linux.qobuzify` or `packages.aarch64-darwin.qobuzify` in a NixOS/Home Manager or nix-darwin package list. Linux reuses Nixpkgs mpv through the upstream-supported `QZ_MPV` setting.

The v0.3.9 desktop assets were replaced on 2026-10-20. The hashes match the SHA-256 digests published by GitHub for the [upstream release](https://github.com/matthewprince/qobuzify/releases/tag/v0.3.9): Linux AppImage asset 658588333 and macOS ZIP asset 658588334. Source downloads remain hash-checked.
